## Descrição

Este repositório contém o código do meu portfólio pessoal, desenvolvido com o objetivo de apresentar minhas habilidades, projetos e experiências de forma clara, objetiva e organizada.

O projeto foi pensado com foco em simplicidade, performance e boa usabilidade, oferecendo uma navegação intuitiva e sem distrações.

Além disso, o repositório é aberto para contribuições, sendo um espaço onde outros desenvolvedores também podem colaborar e sugerir melhorias.

## Objetivo

- Apresentar meus projetos e experiências
- Servir como vitrine profissional
